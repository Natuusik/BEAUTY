# 🧴 AURA Beauty — Витрина интернет-магазина косметики

Интерактивный пет-проект (веб-приложение) интернет-магазина уходовой и декоративной косметики с динамическим каталогом, выдвижной корзиной (Cart Drawer) и автоматическим пересчетом стоимости заказа.

🔗 **[Посмотреть живое демо (Live Demo)](https://ваша-ссылка-на-проект.github.io)**

---

## ✨ Основной функционал

- **Динамический каталог товаров:** рендеринг карточек из массива данных (бейдж, описание, объем, тип кожи, цена).
- **Умные кнопки добавления:** кнопка «В корзину» меняет состояние на «В корзине (N) →» при добавлении товара и открывает корзину по повторному клику.
- **Выдвижная боковая корзина (Drawer):**
  - плавная анимация открытия/закрытия;
  - закрытие по клику на затемненный фон (`overlay`), крестик или клавишу `Esc`;
  - изменение количества каждой позиции (`−` / `+`), удаление отдельного товара (`✕`) и полная очистка корзины.
- **Автоматический расчет итогов:**
  - подсчет общего количества единиц и суммы заказа в реальном времени (в шапке и внутри корзины);
  - **система промокодов:** при вводе `BEAUTY15` применяется скидка **15%**;
  - **умный расчет доставки:** при заказе от **3 500 ₽** доставка становится бесплатной, а до этого порога отображается подсказка, сколько не хватает до бесплатной доставки.
- **Адаптивная верстка:** корректное отображение на десктопах, планшетах и смартфонах.

---

## 🛠 Стек технологий

Проект написан на чистых веб-технологиях без использования сторонних библиотек и фреймворков:
- **HTML5** — семантическая разметка, ARIA-атрибуты для доступности.
- **CSS3** — CSS Grid, Flexbox, плавные CSS-переходы (`transitions`), адаптивность (`@media`).
- **JavaScript (ES6+)** — управление состоянием корзины, работа с DOM, форматирование чисел (`toLocaleString`).
